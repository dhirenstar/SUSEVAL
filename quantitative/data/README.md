Download the following files from the sources and move them to this folder. Ensure they are named correctly:
1. `participant-tracker.csv`: Go to SUSEVAL Participant Tracker Real and export to csv.
2. `SUS_en.csv`: Go to the English SUS form, open the corresponding excel sheet, and Export As CSV UTF-8.
3. `SUS_xh.csv`: Go to the isiXhosa SUS form, open the corresponding excel sheet, and Export As CSV UTF-8.
4. `SUS_en-af.csv`: Go to the English + Afrikaans SUS form, open the corresponding excel sheet, and Export As CSV UTF-8.
5. `SUS_af.csv`: Go to the Afrikaans SUS form, open the corresponding excel sheet, and Export As CSV UTF-8.

This is the raw data that will be processed to produce the various outputs. The contents of this folder are not tracked as they contain sensitive participant data.
